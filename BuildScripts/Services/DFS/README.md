# DFS

## Purpose

Installs and configures Distributed File System.

## Example contents

DFS Namespace and DFS Replication installation and configuration, including the existing DFSN&R.ps1.

## Scope

Receives environment values from the deployment. Ongoing administration and assessment belong in InfraTools.

## Dependencies

Accessible Windows file servers, target paths, and AD or replication prerequisites for the selected configuration.
