# HyperV

## Purpose

Provisions virtual machines and their resources on Hyper-V.

## Example contents

VM, VHDX, and virtual NIC creation and connection to an existing virtual switch.

## Scope

Install guest server roles with `../../BuildScripts/Services`. Hyper-V host operations belong in `InfraTools/HyperV`.

## Dependencies

Requires access to a Hyper-V host, the Hyper-V PowerShell module, and permissions for the selected resources.
