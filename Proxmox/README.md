# Proxmox

## Purpose

Provisions virtual machines and their resources on Proxmox VE.

## Example contents

Cloning a template, creating disks, and configuring virtual NICs and bridges.

## Scope

Install guest server roles with `../BuildScripts/Services`. Operations for existing PVE environments belong in `InfraTools/Proxmox`.

## Dependencies

Requires access to Proxmox VE and permissions for the node, storage, network, and any template used.
